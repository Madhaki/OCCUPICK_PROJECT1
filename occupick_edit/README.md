# OccuPick Website

A responsive front-end prototype based on the OccuPick presentation.

## Open in VS Code
1. Extract the ZIP.
2. Open the `occupick_site` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Included
- Responsive landing page
- OccuPick branding
- Client and worker journeys
- Physical vs digital work
- Swipe/match demo card
- Post-a-task modal
- Login/sign-up modals
- Light/dark theme
- Mobile responsive layout

This is a front-end prototype. Authentication, database, real payments, real-time chat/video, and production matching logic are not connected yet.
